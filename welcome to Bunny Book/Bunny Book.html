🐰📕Bunny Book

A cozy popup notebook for quick notes, edits, and voice typing.

Core Features

  • Create and manage multiple notes in one popup
  • Search notes by title or body with instant filtering
  • Edit with manual save and autosave support
  • Export any note body as a .txt file
  • Use voice typing with a built-in Mic/Stop toggle (🚧feature in progress and may not be fully functional)

❓How to Use

  1. Click the Bunny Book extension icon
  2. Press New to start a blank note
  3. Add a title and body text
  4. Use Save or press Ctrl+S (Cmd+S on Mac)
  5. Use Back or Escape to return to your note list

Editor and Notes Workflow

  • Notes are sorted by most recently updated
  • Each note shows title, timestamp, and one-line preview
  • Title length is capped at 80 characters
  • Delete uses a confirmation step to avoid accidental removal
  • Autosave runs after a short debounce when content changes

Voice Typing

  • The voice typing feature is still in development and may not be fully functional in all browsers.

Compatibility and Permissions

Built as a Manifest V3 Chrome extension popup.

Uses only the storage permission and stores notes locally via chrome.storage.local.

🔒Privacy

Your notes are stored on your device in extension local storage.

No background script or content script tracking is required for core usage.

FAQ

Where are my notes saved?
Notes are saved in chrome.storage.local on your device.

Can I recover a deleted note?
Deletion is permanent after confirmation, so export important notes when needed.

Why is voice typing not working?
Voice typing is still being developed and may not be fully functional in all browsers.
