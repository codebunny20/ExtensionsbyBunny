Bunny Mathbox

An all-in-one extension popup for fast everyday calculations and conversions.

What It Does

Bunny Mathbox is an all-in-one browser extension panel that gives users fast everyday math tools in one clean popup. It combines a standard calculator, ratio calculator, Ohm's law helper, voltage calculator, resistor selector, battery series/parallel calculator, and a multi-category unit converter, with built-in help for each tool so users can solve problems quickly without leaving the page.

Short Version for Cards

Bunny Mathbox puts calculators and converters in one quick popup for fast, practical calculations.

Feature Highlights

  • Multiple tools in one extension popup
  • Engineering-focused calculators (Ohm's, voltage, resistor, battery)
  • Broad unit conversion support for length, mass, temperature, time, data, speed, area, volume, pressure, energy, power, angle, frequency, and force
  • Simple guided help panel for every tool
  • Quick, lightweight workflow for everyday study and work tasks

Tools Included

  • Standard calculator
  • Ratio calculator
  • Ohm's law helper
  • Voltage calculator
  • Resistor selector
  • Battery series and parallel calculator
  • Multi-category unit converter

How to Use

  1. Open Bunny Mathbox from your browser toolbar.
  2. Select the tool you need from the popup panel.
  3. Enter values and read the result instantly.
  4. Use the built-in help panel if you need guidance for the selected tool.
