Auto Scroll

Hands‑free scrolling for any webpage.

Core Features

  • Start/stop auto‑scroll instantly
  • Adjustable scroll speed
  • Smooth or step‑based scrolling
  • Pause on user input
  • Works on any website

How to Use

  1. Click the Auto Scroll extension icon
  2. Choose your scroll speed
  3. Press Start
  4. Interact with the page to pause
  5. Press Stop to end auto‑scroll

Settings Overview

  • Speed slider
  • Smooth mode toggle
  • Horizontal scroll toggle
  • Pause‑on‑input toggle

Compatibility

Works on Chrome and all Chromium‑based browsers.

No special permissions required.

Privacy

This extension does not collect, store, or transmit any data.

FAQ

Why does scrolling stop sometimes?
Some sites override scroll behavior. Auto Scroll pauses when the page captures input.

Does it work on PDFs?
Yes, but speed may vary depending on the viewer.
